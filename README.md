# Hola, soy Stephano.

Soy el fundador de 8+Core, un laboratorio de software Apple que funciona
como una agentic software factory potenciada por Claude. Con una
infraestructura de IA propia, diseñada y construida por mí, creamos
software nativo para iPhone, iPad, Mac y todo el ecosistema Apple. Si
tienes una idea, o eres una consultora o empresa que necesita un equipo
Apple especializado, escríbeme a hola@8pluscore.com o visita
[8pluscore.com](https://8pluscore.com).

Soy iOS developer desde hace años. Me formé en la Apple Developer Academy
de Nápoles y viví casi una década en Italia, entre estudios y más de seis
años trabajando en proyectos FinTech, con aplicaciones usadas por
millones de usuarios y desafíos de arquitectura, seguridad y experiencia
de usuario. Ahí aprendí la importancia de construir software sostenible,
bien pensado y preparado para evolucionar.

Decidí volver a Perú para aportar lo aprendido y construir desde aquí,
para Latinoamérica. Así nació 8+Core.

iOStephano es mi canal, donde comparto lo que hago: novedades del
ecosistema Apple y de Claude, y cómo trabajo con IA en el desarrollo real
de software.

¿Tienes un proyecto en mente? Escríbeme a hola@8pluscore.com.
